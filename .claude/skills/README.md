# Agent-Skills

Die Skills in diesem Ordner stammen aus [mattpocock/skills](https://github.com/mattpocock/skills)
(Version 1.3.2, Commit `4ae2317`), MIT-Lizenz – siehe `LICENSE-mattpocock-skills`.

Übernommen wurden genau die Skills des offiziellen Plugins (ohne die Ordner „in-progress“ und „misc“).
Die Dateien `agents/openai.yaml` (nur für Codex) wurden weggelassen; sonst sind die Dateien unverändert.

Claude Code lädt die Skills beim Start einer Sitzung in diesem Repository automatisch.
Einstieg: `/ask-matt` (welcher Skill passt?) und einmalig `/setup-matt-pocock-skills`.

Aktualisieren: Dateien aus dem Original-Repository erneut hierher kopieren.
